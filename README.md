# 桃夭 · B站每日白嫖 & 经验（油猴脚本）

作者：[LHuiMeng](https://github.com/LHuiMeng) · 版本 v1.5.0

进 B 站自动把每日经验任务和能白嫖的东西做完，右下角一块小面板逐条报结果。

## 装

**方式一（推荐，能自动更新）**：装好 Tampermonkey 后直接打开：

```
https://raw.githubusercontent.com/LHuiMeng/bili-daily-userscript/main/bili-daily.user.js
```

Tampermonkey 会弹安装页。脚本头里写了 `@updateURL`，之后推新版你这边会自动提示更新。

**方式二**：Tampermonkey 面板 →「添加新脚本」→ 把 `bili-daily.user.js` 全文粘进去 → Ctrl+S。

装好打开 https://www.bilibili.com/ ，右下角出现「桃夭 · B站每日 v1.5.0」，2.5 秒后自己开跑。

> **排障前先看标题那行的版本号。** 拿旧版的输出判新版，会白忙一轮（已经踩过一次）。

## 它干什么

| 任务 | 接口 | 说明 |
| --- | --- | --- |
| 登录态 | `GET /x/web-interface/nav` | 显示等级、硬币、大会员 |
| **今日真实经验** | `GET /x/member/web/exp/log` | 最近一周的经验流水（`delta`/`time`/`reason`），汇总今天每条记录，面板显示 `今日 +65（登录5 · 视频投币50 · 观看视频5 · 分享视频5）` |
| 任务判定 | 同上（经验明细） | **不看 `exp/reward` 的布尔字段**——它实测会把已经到账的登录奖励报成未完成 |
| 观看视频 +5 | `POST /x/click-interface/click/web/h5` → `POST /x/click-interface/web/heartbeat` ×2，兜底真播放 | 先走三步接口上报（先报「进入视频页」，再报「开始播放」，5 秒后把进度推到接近片尾）；**接口层无效就自动开小窗真播 30 秒**，让真播放器自己发心跳。只发心跳一定不算数（真机验证过） |
| 分享视频 +5 | `POST /x/web-interface/share/add` | 发完复查 `exp/reward.share`，不轻信 `code:0` |
| 投币（每枚 +10，日上限 50） | `GET /x/web-interface/coin/today/exp`、`POST /x/web-interface/coin/add` | 先查今天已得多少投币经验，只补差额；投前查 `archive/coins` 确认没投过 |
| 大会员每日经验 +10 | `POST /x/vip/experience/add` | 需先完成观看 |
| 大会员每月权益 | `GET /x/vip/privilege/my`、`POST /x/vip/privilege/receive` | B 币券、会员购券等，只在「可领」时动手 |
| 漫画签到 | `POST manga.bilibili.com/twirp/activity.v1.Activity/ClockIn` | 每天一次 |
| 银瓜子换硬币 | `GET /xlive/revenue/v1/wallet/getStatus`、`POST /xlive/revenue/v1/wallet/silver2coin` | 先看今天还剩几次、银瓜子够不够 700（不够就跳过，不硬发） |
| 直播签到 | `GET /xlive/web-ucenter/v1/sign/DoSign` | **官方已下线**，脚本会显示「官方已下线」，留着只为某天复活 |
| 大会员积分签到 | `POST /pgc/activity/score/task/sign2` | Referer 必须是 `big.bilibili.com`。脚本自己挂隐藏 iframe 进去跑，**不用你切页面**；15 秒没回话就报「借道超时」 |

满额一天 65 经验（登录 5 + 观看 5 + 分享 5 + 投币 50）+ 大会员 10 经验。

## 需要特定子域的操作怎么自动做

`sign2` 只认 `big.bilibili.com` 的 Referer，而 fetch 改不了 Referer。脚本的做法是：在页面里挂一个隐藏 iframe 指向 `big.bilibili.com/mobile/bigPoint/task`，脚本会在 iframe 里被注入（所以本脚本没有 `@noframes`），那次请求的 Referer 天然就是对的；跑完用 `postMessage` 带 nonce 回传结果，父页面校验后拆掉 iframe。

实测依据：该域没有 `X-Frame-Options`、没有 CSP `frame-ancestors`，也没有 frame-busting（嵌入后父页面 URL 不被顶走）；**真实登录态下已跑通**，返回 `+5 积分 · 累计 1/7 天`。

iframe 里的脚本只做被指派的那一件事：不挂面板、不抢锁、不写每日标记。其它 iframe 一律直接 return，避免页面内多个 frame 重复跑全套任务。

## 为什么要用「经验明细」判成败

> 这个数据源和你在 [account.bilibili.com/account/record](https://account.bilibili.com/account/record) 看到的「经验记录」是同一个：账户中心的 JS bundle 里同时引用了 `x/member/web/exp/log`、`x/member/web/coin/log`、`x/member/web/exp/reward`。面板上 `今日已得经验` 那行 = 你在那个页面看到的东西，不用再对着两个地方数。

经验明细有延迟（几分钟到几小时不等），所以任务跑完当场查不到是正常的。脚本遇到这种情况标 **`◔ 待核验`**，不判死；收尾时只查一次明细，到账了就自动升级成 `✓ 收尾核验：明细已到账`。

`GET /x/member/web/exp/reward` 返回的 `login` / `watch` / `share` 三个布尔字段**不可靠**：真机实测里登录奖励早就自动到账了，它照样返回 `false`。拿它判成败，就会把「已到账」误判成「没做」，然后一遍遍重试。

v1.4.0 起改用 `GET /x/member/web/exp/log`（经验流水）：只要今天的记录里有 `reason` 含「观看」「分享」「投币」的条目，就算到账；没有就是 B 站真的没给。面板顶部那行 `今日已得经验` 就是它算出来的，收尾再刷一次。

## 不想看的时候：点 ×

悬浮面板标题栏最右边有个 `×`：

- 点它 → 面板立刻消失，**当天所有 B 站页面都不再出现**（包括不再自动跑，免得你看不到进度却花了硬币）。
- **第二天自动恢复**，不需要手动做什么。
- 想当天就叫回来：Tampermonkey 菜单 →「重新显示悬浮窗（今天）」，标记清掉、面板回来，今天要跑再点「重跑」。

另外面板跑完 15 秒会自动收成一条细条（只剩标题和完成数），也可以再点标题折叠/展开。

## 菜单

Tampermonkey 菜单里有四项：

- **⚙ 设置（功能开关 / 上次执行）** — 11 个开关 + 3 个数值 + 今日经验 + 上次执行时间
- **重新显示悬浮窗（今天）** — 用 × 关掉之后，当天想叫回来就用这个
- **打开经验记录页（核对到账）** — 直接开 `account.bilibili.com/account/record`
- **立即重跑 B站每日**
- **清除「今天已跑」标记**

## 设置面板（v1.3.0）

Tampermonkey 菜单 →「⚙ 设置（功能开关 / 上次执行）」，弹出面板里：

- **11 个开关**：观看视频 / 分享视频 / 投币 / 真播放补观看 / 大会员每日经验 / 大会员每月权益 / 大会员积分签到 / 漫画签到 / 银瓜子换硬币 / 直播签到 / 进页面自动运行。关掉的项运行时直接跳过，面板上显示「配置已关闭」。
- **3 个数值**：每次最多投币、硬币保留线、真播放秒数。
- **上次执行**：显示上次跑完的本地时间、距今多久、今天是否已跑过。

保存即生效（不用刷新页面），配置存在 `GM_setValue('tyBiliConfig')`，只覆盖面板里那几个键，其它默认值不受影响。

## 真播放补观看（v1.3.0）

纯接口上报 B 站不认（真机验过：`code:0` 但 `exp/reward.watch` 一直是 false）。所以接口层失败后，脚本会在右下角开一个 360×203 的悬浮小窗，加载视频页并静音播放，让真播放器自己发心跳；播到指定秒数或播放器 10 秒不动就收手，然后复查任务状态。

为什么用 iframe 而不是 `window.open`：无用户手势的 `window.open` 会被浏览器弹窗拦截，而页面内 iframe 不受这个限制。

## 怎么改

脚本开头 `CONFIG` 那段，改完保存刷新页面即可：

```js
coin: true,        // 不想花硬币就改 false
coinPerRun: 5,     // 单次最多投几枚（5 枚 = 满 50 经验）
keepCoins: 20,     // 硬币余额低于这个数就不投了
selectLike: false, // 投币时是否顺带点赞（会进你的点赞列表，默认关）
manga: true,       // 漫画签到
silver2coin: true, // 银瓜子换硬币
autoRun: true,     // 进页面自动跑
```

Tampermonkey 菜单里还有「立即重跑 B站每日」「清除『今天已跑』标记」。

## 几个刻意的设计

- **不碰密码**：全部走你浏览器里的登录态（`SESSDATA` / `bili_jct`），脚本自己读不到也存不了。
- **一天只跑一次**：跑完写本地标记，当天再进页面不会重复；多标签页有跨标签页锁，不会两边同时投币。
- **投币前查余额和已投**：`archive/coins` 确认这个稿件没投过，`keepCoins` 兜底，避免把硬币投干。
- **风控就收手**：分享遇 `-403`、投币遇非预期错误码直接停，不做无意义重试（越试越黑）。
- **面板即日志**：每条任务单独 try/catch，一条失败不影响其它；哪条不对，看面板那行返回码就够定位。

## 已知边界

- 直播宝箱、天选时刻抽奖、粉丝勋章任务没做——这些要真进直播间挂心跳、自动关注/发弹幕，风控和骚扰都太重，不做。
- 「绑定手机/邮箱」那 50/100 经验是一次性任务，接口没法代做。
- **v1.3 报的「观看 30 秒仍未到账」是误报**：那版还在读 `exp/reward.watch`（坏字段），实际经验在「经验记录」里已经到账了。v1.4.1 起只看经验明细，并且把「接口成功但明细没刷新」单独标成 `待核验`，不再冤枉任务。
- 若连续几天 `待核验` 到收尾都没变成 `✓`，那才是真没给，届时把 `watch` 关掉即可。
- **直播签到是 B 站自己停的活动**，不是脚本问题、也不是风控。接口 `GET /xlive/web-ucenter/v1/sign/DoSign` 还活着，但只回 `code:1「签到活动已下线，无法使用。」`，没有替代接口。脚本保留调用只是为了某天复活。
- 「本次经验 +X」这个汇总不可靠——`nav` 里的 `current_exp` 有刷新延迟，以站内经验页为准。
- 若你登录态失效，借道 iframe 会被跳到 passport 登录页，15 秒后报「借道超时」——那是登录问题，不是脚本问题。
